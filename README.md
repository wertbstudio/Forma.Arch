# FORMA.ARCH — этап 1

Темный журнальный сайт архитектурного бюро. HTML, CSS и JavaScript без библиотек и сборки. Серверная функция Vercel использует встроенный `fetch`; npm-зависимостей нет.

## Локальный запуск

1. Установите Node.js 22 или новее.
2. Откройте терминал в `C:\ProjectsGPT\forma-arch`.
3. Скопируйте `.env.example` в `.env` и заполните значения для тестирования доставки. Для просмотра дизайна ключи не нужны.
4. Выполните `node dev-server.js`.
5. Откройте `http://127.0.0.1:3000`. Остановка — Ctrl+C. Если порт занят: задайте переменную `PORT` перед запуском.

Локальный сервер отдает только публичные файлы из разрешенного списка и тот же `/api/send`, что на Vercel. Открытие HTML двойным кликом не поддерживает отправку формы.

## Размещение на Vercel

1. Создайте Git-репозиторий с содержимым **этой папки**, загрузите его в свой GitHub. Перед каждым `git push` проверьте все файлы на секреты. `.env` никогда не добавляйте в Git.
2. В Vercel выберите **Add New → Project**, импортируйте репозиторий.
3. **Framework Preset: Other**, **Root Directory:** корень этого репозитория. Если импортирован весь ProjectsGPT, укажите `forma-arch`.
4. Сборка не требуется. `vercel.json` задает корень как Output Directory и функцию `api/send.js`. Не задавайте статический экспорт, исключающий `/api`.
5. В **Environment Variables** добавьте `BOT_TOKEN` (токен вашего бота от BotFather) и `CHAT_ID` (получатель заявок). Укажите Production, а при необходимости Preview. Значения вводите только в защищенных настройках Vercel.
6. Нажмите Deploy. После добавления или изменения переменных сделайте Redeploy.
7. Напишите боту `/start` либо добавьте его в нужную группу. Отправьте тестовую заявку с опубликованного сайта и проверьте получение сообщения.

Не используйте префиксы `NEXT_PUBLIC_`, `VITE_` для секретов. Не передавайте их в HTML, JS или localStorage. При отсутствии настроек сервер вернет понятную ошибку; ложного подтверждения нет.

## Что реализовано

- Крупная типографика Cormorant Garamond + Manrope, заданная палитра, асимметричная композиция.
- Фотографии по прямым HTTPS-ссылкам Unsplash, адаптивное кадрирование, отложенная загрузка второстепенных фото.
- Прогресс прокрутки, появления через IntersectionObserver, параллакс, магнитные кнопки. Учитывается `prefers-reduced-motion`.
- Четыре строки проектов, превью с инерцией через requestAnimationFrame на компьютере; встроенные изображения на телефоне. Клик открывает описание и галерею из трех фото.
- Диалоги с Escape, закрытием по фону, блокировкой прокрутки, удержанием и восстановлением фокуса; мобильное меню.
- Форма с типом объекта, именем, маской телефона +7, согласием, скрытой ловушкой и состояниями загрузки/ошибки/успеха.
- Калькулятор отдельной секцией сразу после «Подхода»: тип пространства, площадь и предварительная стоимость дизайна. Ссылки в меню и на первом экране ведут к секции. Кнопка «Обсудить расчет» открывает форму с выбранным типом и кратким итогом; площадь передается в Telegram. Ставка **демонстрационная**, ремонт и комплектация в нее не входят.
- API: только POST/JSON, ограничение размера, проверка источника браузерного запроса, полей, согласия, honeypot и времени заполнения, таймаут Telegram, отсутствие логирования персональных данных и токенов.
- Ограничение повторных заявок: одна в минуту на IP в пределах работающего экземпляра функции. Для глобального ограничения между экземплярами настройте правило Vercel Firewall/WAF. Это дополнительная защита, не CAPTCHA.

## Заменить перед коммерческим запуском

1. В шапке, контактах и диалоге обработки данных указан предоставленный номер `+7 (495) 740-28-91`; ссылки используют `tel:+74957402891`.
2. Демонстрационные описания, географию, годы, подписи и фотографии — на подтвержденное портфолио. Изображения Unsplash иллюстрируют атмосферу и не являются фотографиями реальных объектов FORMA.ARCH.
3. Цифры «12 лет / 94 объекта» и «с 2012 года» из брифа — подтвердить и актуализировать перед публикацией.
4. Ставку 6 000 ₽/м² согласовать с бюро и синхронно изменить в `script.js`, `api/send.js` и пояснении `index.html`.
5. Утвердить политику обработки данных: оператор, реквизиты, контакт для отзыва согласия, сроки хранения и применимость передачи в Telegram. Диалог содержит краткое описание передачи данных и телефон для обращений; полную политику необходимо утвердить отдельно.
6. Технические подписи о демонстрации убраны из интерфейса по запросу. Фото Unsplash и описания проектов требуют подтверждения перед коммерческим запуском. Hero использует отдельный снимок `photo-1600210492493-0946911123ea`, не повторяющий галереи проектов; его доступность проверена.

Фото и шрифты загружаются с внешних сервисов и требуют доступа к сети. Источники фото находятся в `index.html` и массиве `projects` в `script.js`.

## Проверки

`node --check script.js`, `node --check api/send.js`, `node --check dev-server.js` — синтаксис.

`node --test tests/api.test.js` — валидация API, антиспам, отсутствие конфигурации, успешная доставка, ошибки Telegram и сети. Внешние запросы подменены; реальные сообщения тесты не отправляют.

При создании прошли все 21 проверки Node Test Runner и проверка синтаксиса. Все пять уникальных ссылок Unsplash вернули HTTP 200 с типом image/jpeg. Проверка файлов по шаблонам секретных ключей совпадений не обнаружила.

В среде создания автоматический браузерный предпросмотр недоступен: локальный адрес не открылся, управление Chrome завершилось ошибкой. Поэтому адаптивность и визуальные переходы необходимо дополнительно проверить в браузере на компьютере и телефоне. Доставка в реальный Telegram требует ваших переменных окружения.
